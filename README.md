# I&I Live

A Caribbean live stream platform prototype for seven always-on streamable channels, a private production back channel, stored replay metadata, and YouTube-linked viewer access.

## What is included

- Seven branded live channel cards for DJs, interviews, podcasts, remote pop-ups, and diaspora streams.
- A hero live-player concept for I&I Live.
- A back-channel operations panel for live routing, viewer requests, stored metadata, and YouTube sync.
- A replay archive section that models stored content with YouTube access.
- A programming schedule that shows how live moments become archived replays.

## Run locally

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```
