# WordSlap

A lightweight local prototype for the **WordSlap** party game concept.

This project is intended to stay **private and local-only**. It does not require deploying, publishing, or connecting to any online service.

## Run locally

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open <http://127.0.0.1:4173> in your browser.
